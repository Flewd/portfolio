<h1>Game Summary</h1>

Fight monsters, talk to ghosts, and get to the bottom of a mystery threatening to obliterate an entire city in Usual June, a third-person action-adventure game about combat, cupcakes, and community.

<h1>My Part</h1>

Worked in a custom Unity ECS system to build up Usual June from an early prototype to a released game. Usual June is a 3rd person action adventure game with an even split of combat and narrative systems built in Unity.

<div style={{ textAlign: "left" }}>
- Built a dialog system that uses character and camera positions to show dynamic dialog bubbles in a 3d space.
- Built a responsive and modular animation driven action combat system inspired by games like Bayonetta and Nier: Automata. Designers can markup specific frames with collision and combo flags within unity’s editor.
- Worked with game director to architect, implement, and iterate on core gameplay systems and mechanics.
- Implemented a 3d root motion driven character controller for players, NPCs, Enemies, Pathfinding.
- Implemented packages such as FinalIK, AStar Pathfinding, Bakery Lightmapping.
- Automatic tooling for Unity build shader stripping to reduce build times.
- Worked with artists and designers to build Unity editor tools.
</div>
